# Frontend (Next.js)

Web application and user interface for the Z365 platform.

## 🛠️ Tech Stack
- Next.js (App Router)
- React 18
- TailwindCSS
- Lucide React

## 🚀 Local Development
```bash
cd frontend
npm install
npm run dev
```
Runs at `http://localhost:3000`.

## 🌐 Deployment
- **Target**: Vercel / Firebase App Hosting
- Builds standard static/SSR Next.js artifacts.
